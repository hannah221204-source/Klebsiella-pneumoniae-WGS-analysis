# Klebsiella-pneumoniae-WGS-analysis
Identify carbapenem resistance mechanisms on KP isolates using WGS and bioinformatic tools.
## Objectives
- Identify antimicrobial resistance genes
- Detect porin and efflux regulator gene mutations
- Analyse sequence types
## Workflow
1. Quality control of raw WGS reads
2. Adapter trimming and quality filtering 
3. Host read removal
4. Contamination detection and removal
5. De novo genome assembly
6. Assembly quality assessment
7. Species identification
8. Multilocus sequence typing
9. Genome annotation
10. AMR gene profiling
11. Porin gene analysis 
12. Efflux regulator gene analysis
## Tools
- FastQC
- fastp
- Bowtie2
- Kraken2
- SPAdes
- QUAST
- BUSCO
- FastANI
- Kleborate
- Prokka
- Snippy
